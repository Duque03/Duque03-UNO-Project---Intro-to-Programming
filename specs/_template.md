# Task: short name (for example D3, PIN for each player)

## Why
What is wrong or missing today, in one or two sentences.

## What
What the game must do after this change. Refer to docs/game-design.md where it applies.

## Out of scope
What this task will not touch, so the agent and the reviewer know where to stop.

## Done when
- A test for an accepted action passes.
- A test for a rejected action passes (and the saved data is unchanged).
- Checked by hand: allowed action, rejected action, restart the app.
